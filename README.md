# FX Anomaly Scanner

MT5 から 5 分足を取得し、「特定の時刻に建てて N 時間後に決済する」を総当たりで検証するツールです。

**31 銘柄 × エントリー 48 時刻 × 保持 3〜12 時間 × 売買 = 28,680 通りを約 36 秒**で回します。

解説記事: https://web-lukes.info/articles/anomaly-search-tool-usage-2026

---

## ⚠️ 先に読んでください

このツールは**候補を出す装置**であって、**判定する装置ではありません。**

29,000 通り試せば、偶然だけで「勝率 77%」「Sharpe 0.9」は出ます。実際、この探索の 6 ヶ月版で最上位に来たセルの t 値は 4.34 でしたが、**28,680 回の独立な検定で偶然に出る最大 t 値の目安は 4.14** です。ほぼ差がありません。3 ヶ月版に至っては、閾値を超えたセルが 1 つもありませんでした。

出力の読み方は下の「[出力の読み方](#出力の読み方)」を必ず通してください。

### 探索グリッド

| 項目 | 内容 |
|---|---|
| 銘柄 | 31（FX 29 + XAUUSD + JP225 + US30） |
| エントリー時刻 | 24 時間 × 00 分 / 30 分 = 48 通り |
| 保持時間 | 3〜12 時間 = 10 通り |
| 方向 | Long / Short |
| 期間 | 直近 30 日 / 90 日 / 180 日 |
| コスト | 往復 1 スプレッド（MT5 のバーごとの**実測値**） |
| フィルタ | スプレッドが平均の 5 倍超のバーではエントリーしない |

### 設定

```python
PERIODS = [('1m', '1 Month', 30), ('3m', '3 Months', 90), ('6m', '6 Months', 180)]
ENTRY_MINUTES = [0, 30]      # [0] だけにすれば実行時間が半分
HOLD_HOURS = range(3, 13)    # デイトレなら range(1, 7) など
```

### 出力


`results/` の CSV を同梱しているのは、**TOP100 だけ見ても判断できないから**です。下の読み方で全セルを使います。

## 出力の読み方

### 1. t 値を出して、検定数から決まる閾値と比べる

このツールの `sharpe` 列は **1 トレードあたりの mean ÷ std**（年率化していません）。なので t 値はこう出ます。

```python
import pandas as pd, numpy as np
from scipy import stats

d = pd.read_csv("results/strategies_6m.csv")
d["t"] = d.sharpe * np.sqrt(d["count"])

# 検定数から決まる「偶然に出る最大t値」の目安
thr = stats.norm.ppf(1 - 1 / (2 * len(d)))
print(f"検定数 {len(d):,} → 偶然の目安 t={thr:.2f}")
print(f"観測された最大 t={d.t.max():.2f}")
print(d[d.t > thr][["symbol","direction","entry","exit","sharpe","count","t"]])
```

閾値を超えないものは、**ランキング 1 位でも根拠になりません。**

### 2. TOP100 の方向の偏りを見る

```python
top = d.nlargest(100, "sharpe")
print(top.direction.value_counts())
```

片側に極端に寄っていたら、時間帯アノマリーではなく**その期間のドリフト**を拾っている可能性を疑ってください。

### 3. 全セル平均でドリフトと裾の選択を分ける

これが一番効きます。

```python
g = d.groupby(["symbol","direction"]).avg_return.mean().unstack() * 100
print(g.join(top.groupby("symbol").size().rename("TOP100本数")).sort_values("long", ascending=False))
```

- **long の全セル平均がはっきりプラス** → その銘柄が上がっただけ。時刻を変えても消えません（＝アノマリーではない）
- **全セル平均がほぼゼロなのに TOP100 に多数** → 960 通りの右端を選んだだけ

### 4. 期間を入れ子にしない

`PERIODS` の 30 / 90 / 180 日は、1 回取得したデータをスライスしているだけなので**入れ子**です。3 ヶ月は 6 ヶ月の中に含まれます。

REPORT.md の「期間横断で一致した戦略」は**独立した検証ではありません。** 検証するなら、前半 90 日で選んで後半 90 日で試す、のように重ならないよう割ってください。

## 実例：前バージョンの 1 位を引き直した結果

2026 年 3 月にこのツールの前バージョンで探索したとき、1 位はこれでした。

```
GBPAUD long 18:30 -> 00:30 (6h)
勝率 85.7%   Sharpe 0.849   28,680通り中 1位
```

半年後、同じ戦略を同じ探索で引くと。

```
Sharpe -0.188   勝率 38.8%   23,586位 / 28,680
```

TOP3 が 3 つとも下位 2 万番台に沈み、GBPAUD は 6 ヶ月版の TOP100 に 1 本も残っていませんでした。

**消えたのではなく、最初から測れていなかった**というのが妥当な解釈です。当時の私は上の読み方 1〜4 を、ひとつもやっていませんでした。
